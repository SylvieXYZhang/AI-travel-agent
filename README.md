# Japan Diaries Card Demo

一个零依赖的旅行卡片交互 Demo，参考移动端叠放卡片视觉实现。

## 本地运行

直接打开 `index.html`，或使用 Node.js 启动本地服务：

```powershell
node server.cjs
```

然后访问 <http://127.0.0.1:4173>。

## 交互

- 点击卡片、按左右方向键或在手机上横向滑动，可切换目的地。
- 点击当前卡片底部的 `+`，按钮会展开为 AI 输入框。
- 输入旅行需求并发送后，会展示思考状态，随后生成并打开一张 AI 回复卡片。
- 新生成的卡片可以继续提问并生成后续卡片。

## 实现说明

- 单文件 HTML、CSS 和原生 JavaScript，无第三方运行时依赖。
- 城市插画位于 `assets/`，可离线显示。
- 卡片布局会根据卡片数量和屏幕宽度动态调整，确保正文、指标、输入框和按钮处于安全内容区。
- AI 回复为前端 Demo 数据，不连接真实模型服务。

## 验证

- JavaScript 语法检查通过。
