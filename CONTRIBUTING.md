# Contributing

Thank you for helping improve VoyageAI.

1. Open an issue for substantial product or architecture changes.
2. Create a focused branch and keep unrelated changes separate.
3. Run `npm test` before opening a pull request.
4. Never commit `.env`, API keys, cookies, user data, cloud identifiers, deployment archives, or service logs.
5. Add tests for behavior changes and update the README when user-facing behavior changes.
